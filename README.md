# E-Bike

## About
This is a E-bike, or electrical motor powered bike. This project will use user input, to controll a motor attached to a bycle wheel. The project is based off of a ESP32 and a (Insert bike).

## Files
Inside of this github are the following files
- Cad files for the motor housing
- PCB layouts and schematics
- ESP32 Code
- A Bill of Materials (BOM) in a .csv file format
